# Blog Post 4: U.S. State Population Growth, 2020–2025

This repository contains the data, R code, and figures for an analysis of population growth across the 50 U.S. states.

## Research question

Which states experienced the fastest population growth between July 1, 2020, and July 1, 2025? How do rankings by percentage growth differ from rankings by the number of additional residents?

## Data source

The analysis uses the U.S. Census Bureau’s Population Estimates Program, Vintage 2025, file `NST-EST2025-ALLDATA.csv`.

- [Official CSV dataset](https://www2.census.gov/programs-surveys/popest/datasets/2020-2025/state/totals/NST-EST2025-ALLDATA.csv)
- [Variable definitions](https://www2.census.gov/programs-surveys/popest/technical-documentation/file-layouts/2020-2025/NST-EST2025-ALLDATA.pdf)

The sample includes all 50 states and excludes Washington, D.C., Puerto Rico, and national or regional aggregates. Population values are July 1 estimates for each year from 2020 through 2025. All years come from the same vintage to maintain consistency.

The script downloads the original CSV when it is absent and records the source and download time in `data/raw/data_source.txt`. Subsequent runs use the saved local copy.

## Repository organization

- `blogpost4_all_process.R`: complete analysis script, including data acquisition, cleaning, calculations, validation, and figure generation.
- `blogpost4_all_process.Rproj`: RStudio project file.
- `data/raw/`: original Census CSV and source information.
- `data/processed/`: cleaned population data, state-level summary, state-year data, and R session information.
- `figures/`: three PNG figures generated by the script.

The analysis is maintained in one script in the repository root.

## How to reproduce the analysis

1. Download or clone this repository.
2. Open `blogpost4_all_process.Rproj` in RStudio.
3. Install the required packages once:

```r
install.packages(c("ggplot2", "ggrepel"))
```

4. Run the complete script from the project root:

```r
source("blogpost4_all_process.R")
```

The script creates the necessary output folders, reads or downloads the data, checks the 50-state sample, calculates population changes, and saves all three figures.

Internet access is needed to install packages and to download the raw data if the local CSV is absent. The R and package versions used during execution are recorded in `data/processed/session_info.txt`.

## Measures

- **Population change:** population in 2025 minus population in 2020.
- **Cumulative growth rate (%):** population change divided by population in 2020, multiplied by 100.
- **Population index:** population in a given year divided by population in 2020, multiplied by 100.

Growth rates describe the entire 2020–2025 period, not annual growth.

## Figures

1. **State population growth:** all 50 states ranked by cumulative percentage growth.
2. **Population trajectories:** annual population indices for the three highest-growth and three lowest-growth states, selected using cumulative growth rates.
3. **Growth rates versus population gains:** percentage growth plotted against population change in millions for all 50 states. Labels identify the top three states by either measure.

## Main findings and limitations

Idaho had the highest cumulative population growth rate, while Texas added the most residents. These rankings differ because percentage growth is measured relative to each state’s initial population.

The analysis is descriptive. It does not identify the causes of population changes or separate migration from natural increase. Population estimates may be revised in later Census releases.
